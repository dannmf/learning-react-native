# Lista 01 - JSX Básico e Expressões

**Desenvolvimento Mobile | React Native**

---

**Objetivo:** Praticar a estrutura básica de JSX, interpolação de variáveis e chamada de funções dentro do JSX.

---

## Exercício 1 — View com Text

Crie um componente funcional que retorne dois textos dentro de um contêiner. O primeiro texto deve exibir **"Olá"** e o segundo **"Mundo"**.

---

## Exercício 2 — Variáveis no JSX

Dado as variáveis abaixo já declaradas no componente:

```js
const linguagem = "JavaScript";
const ano = 2025;
```

Exiba na tela os textos **"Linguagem: JavaScript"** e **"Ano: 2025"**, utilizando os valores das variáveis de forma dinâmica.

---

## Exercício 3 — Função no JSX

Dado a variável abaixo:

```js
const preco = 49.9;
```

Crie uma função chamada **formatarPreco** que receba um número e retorne uma string no formato monetário brasileiro (ex: **"R$ 49.90"**). Em seguida, chame essa função dentro do JSX para exibir o preço formatado.
